# 算法面试笔记

> 147 道题的 Java 解题笔记，按数据结构和算法模式拆分为可独立阅读的章节。

每道题依次给出题意、思路推导、例子、正确性关键、边界、复杂度和实现。建议先遮住代码，自己讲清楚思路后再核对实现。

[阅读说明、面试表达与代码约定](algorithm-interview/introduction.md)

## 推荐起点

第一轮可先练这 32 道题，覆盖主要面试模式：

`283、88、11、15、128、3、209、560、35、34、33、21、19、141、142、20、739、215、146、295、98、108、236、124、200、994、46、55、45、53、300、1143`。

优先级 A 表示基础主线，B 表示重要变体，C 表示可后置的难题或细节题；它们是本笔记的复习建议，并非题频统计。
