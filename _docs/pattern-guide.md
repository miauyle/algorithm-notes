# 题型识别与解题套路

这页用于做题前的判断和做题后的复盘。各章开头讲本章的共同性质，具体题目讲推导和 Java 实现；这里把跨章节的选择依据放在一起。**先看问题要求，再找能利用的性质，最后决定用什么结构和方法。**一题可以同时属于多个类型，例如树上的路径和可以用前缀和，树上最优选择可以用动态规划。

如果只是面试前快速回忆，先扫[算法面试速查表](cheat-sheet.md)；如果正在安排 3 / 7 / 14 天复习节奏，直接看[面试冲刺路线](interview-sprint.md)。本页保留更完整的“为什么选这个模式”的判断依据。

## 先问五个问题

1. **求什么？** 判断是否存在、求一个最优值、统计个数，还是枚举全部方案？即使输入相同，目标不同也可能换解法。
2. **范围是什么？** 连续区间、任意子序列、整棵子树、图上的一条路径，还是所有节点？“连续”通常是重要信号。
3. **有什么可用性质？** 有序、全为正数、元素值域有限、无权边、搜索树性质、可重复选取等。说出依赖的前提。
4. **需要记住什么？** 已处理区域、历史前缀频次、仍有希望的候选、递归返回值、某个状态的最优答案。
5. **为什么能排除其他选择？** 指针移动、二分丢半边、单调栈弹出、贪心决定、回溯剪枝，都要有可解释的理由。

下面每类给出识别信号、核心套路和现有题目。链接直接进入题解，无须为这页重复刷一套题。

## 01 数组、哈希与双指针

**看到什么：** 原地调整、两个方向寻找答案、去重或“是否出现过”。先确认能否改动数组、是否有序、是否需要保留原下标。

- **原地读写：** 用 `write` 划定已完成的前缀，`read` 扫描剩余部分；每轮说清已处理区域。见 [283 移动零](01-array-two-pointers.md#q-283)、[88 合并两个有序数组](01-array-two-pointers.md#q-88)。后者从尾部写入，避免覆盖还没读到的值。
- **相向指针：** 排序或目标函数的性质决定移动哪端；证明被舍弃的一端无法产生更好答案。见 [11 盛最多水的容器](01-array-two-pointers.md#q-11)、[15 三数之和](01-array-two-pointers.md#q-15)。
- **哈希：** 当问题需要快速判断“见过没有”或按特征分组，用集合或映射保存恰好需要的信息。见 [128 最长连续序列](01-array-two-pointers.md#q-128)、[49 字母异位词分组](01-array-two-pointers.md#q-49)。哈希能加快查询，但不能替代顺序、连续性或去重的证明。

## 02 滑动窗口与前缀和

**看到什么：** 连续子数组或子串。先区分求长度、最值还是个数，并检查窗口条件能否随着左右端单向移动。

- **窗口：** 右端扩张，左端在某个条件下持续收缩；明确记录答案是在收缩前还是恢复合法后。见 [3 最长无重复子串](02-sliding-window-prefix.md#q-3)、[76 最小覆盖子串](02-sliding-window-prefix.md#q-76)。
- **正数和的单调性：** [209 长度最小的子数组](02-sliding-window-prefix.md#q-209)能在达标后缩左端，依赖元素为正。含负数时不能照搬这一套。
- **前缀差：** 区间和等于两个前缀之差；要统计和为 `k` 的区间，就查询此前出现过多少次 `pre-k`。见 [560 和为 K 的子数组](02-sliding-window-prefix.md#q-560)。先查再记录当前前缀，并初始化空前缀频次。

## 03 二分查找

**看到什么：** 有序或可证明的一侧能被排除；所求可能是“第一个满足条件的位置”，而非恰好等于目标的元素。

- 先定义答案和搜索区间，再写循环。找插入点可理解为找第一个 `>= target` 的位置，见 [35 搜索插入位置](03-binary-search.md#q-35)、[34 查找元素的第一个和最后一个位置](03-binary-search.md#q-34)。
- 旋转数组要先判断哪半有序，再判断目标能否落在那半；每次说明保留答案的理由。见 [33 搜索旋转排序数组](03-binary-search.md#q-33)。
- 仅行列分别有序的矩阵未必整体有序。对照 [74 搜索二维矩阵](03-binary-search.md#q-74)与 [240 搜索二维矩阵 II](03-binary-search.md#q-240)，先检查结构再选二分或从角落排除。

## 04 链表

**看到什么：** 删除、插入、反转、倒数位置或环。先画节点关系，给每个指针命名：前驱、当前、下一节点、片段尾。

- **改指向：** 改 `next` 前先保存后继；需要统一处理头节点时放一个 `dummy`。见 [21 合并两个有序链表](04-linked-list.md#q-21)、[24 两两交换链表中的节点](04-linked-list.md#q-24)。
- **快慢指针：** 固定间距找倒数位置；速度差检测环。见 [19 删除倒数第 N 个结点](04-linked-list.md#q-19)、[141 环形链表](04-linked-list.md#q-141)、[142 环形链表 II](04-linked-list.md#q-142)。
- **片段反转：** 明确前驱、段头、段尾、段后节点，检查不足一组时的处理。见 [25 K 个一组翻转链表](04-linked-list.md#q-25)。

## 05 栈与单调结构

**看到什么：** 最近尚未匹配的对象、嵌套关系、下一个更大元素，或固定窗口的极值。

- **普通栈：** 后遇到的对象先完成匹配；入栈保存尚未解决的状态。见 [20 有效的括号](05-stack-monotonic.md#q-20)、[394 字符串解码](05-stack-monotonic.md#q-394)。
- **单调栈：** 新元素到来时，弹出已经找到答案或不再有资格的旧候选；保存下标以计算位置。见 [739 每日温度](05-stack-monotonic.md#q-739)、[84 柱状图中最大的矩形](05-stack-monotonic.md#q-84)。
- **单调队列：** 队头是当前窗口答案；队尾删掉被新值支配的候选，队头删掉过期下标。见 [239 滑动窗口最大值](05-stack-monotonic.md#q-239)。分析复杂度时数每个元素的总进出次数。

## 06 堆与数据结构设计

**看到什么：** 只需保留前 `k` 个候选、持续取极值、动态维护中位数，或题目要求多种操作都高效。

- **堆：** 只维护所需的一端，不必全量排序。[215 数组中的第 K 个最大元素](06-heap-design.md#q-215)保留大小为 `k` 的小根堆；[295 数据流的中位数](06-heap-design.md#q-295)用两个堆维持两半边界。
- **组合结构：** 先列每项操作需要的时间复杂度，再分配职责。[146 LRU 缓存](06-heap-design.md#q-146)用哈希定位、双向链表维护次序；[208 实现 Trie](06-heap-design.md#q-208)用路径上的字符共享前缀。
- 面试时明确堆顶、链头或链尾、节点字段各代表什么；“用了某种容器”本身不是设计理由。

## 07 二叉树与搜索树

**看到什么：** 子树结果需要向上传、逐层处理、找祖先，或利用 BST 的有序性。

- **先定义递归返回值：** 它是高度、单支最大贡献、找到的节点，还是构造好的子树？“返回给父节点的值”与“整棵树的全局答案”可以不同。见 [543 二叉树的直径](07-tree.md#q-543)、[124 二叉树中的最大路径和](07-tree.md#q-124)、[236 最近公共祖先](07-tree.md#q-236)。
- **BST：** 中序遍历给出有序序列，可数第 `k` 小；验证 BST 时需要祖先传下来的范围约束。见 [230 二叉搜索树中第 K 小的元素](07-tree.md#q-230)、[98 验证二叉搜索树](07-tree.md#q-98)。
- **按层处理：** BFS 在每层开始记录队列长度，避免混入下一层。见 [103 二叉树的锯齿形层序遍历](07-tree.md#q-103)。

## 08 图、网格与搜索

**看到什么：** 连通块、无权最少步数、同步传播、先修依赖。先把“顶点是什么、边是什么”说清楚。

- **连通块：** 从每个尚未访问的起点遍历并永久标记，见 [200 岛屿数量](08-graph-search.md#q-200)。
- **无权最短层数与扩散：** BFS 首次入队就标记；多个起点同时扩散时先一起入队。见 [994 腐烂的橘子](08-graph-search.md#q-994)。
- **有向依赖：** 用入度和队列逐步移除可执行节点，见 [207 课程表](08-graph-search.md#q-207)。如果题目要求枚举路径，访问标记的生命周期可能要改为进入标记、退出恢复，不能机械照搬连通块写法。

## 09 回溯

**看到什么：** 列出全部组合、排列、切分或受约束的棋盘方案。先定义路径、可选集合、何时收集答案以及如何撤销。

- **组合与排列：** 组合用起点避免顺序重复；排列用已使用标记决定下一格。见 [39 组合总和](09-backtracking.md#q-39)、[46 全排列](09-backtracking.md#q-46)。
- **切分与约束：** 每次决定下一段的结束点，或维护列和对角线占用；发现当前选择不可能成功就剪枝。见 [131 分割回文串](09-backtracking.md#q-131)、[51 N 皇后](09-backtracking.md#q-51)。
- 保存答案时复制当前路径；递归返回时撤销本层对共享状态的改动。先估计输出规模，别把必须枚举的指数级答案误当成实现低效。

## 10 贪心与区间

**看到什么：** 只需最优值、能持续扩大覆盖范围，或排序后可以逐段决定。但局部看起来最好，不等于一定正确。

- **维护最强候选：** 固定当前卖出位置，只需保留历史最低买入价，见 [121 买卖股票的最佳时机](10-greedy-interval.md#q-121)。
- **覆盖范围：** [55 跳跃游戏](10-greedy-interval.md#q-55)维护最远可达位置；[45 跳跃游戏 II](10-greedy-interval.md#q-45)按当前跳数能覆盖的整层确定下一层。判断可达与求最少次数，状态不同。
- **排序后处理区间：** [56 合并区间](10-greedy-interval.md#q-56)先按左端点排序，再维护当前合并段。说明为什么已封闭的段不可能再被后面的区间改变。

## 11 动态规划

**看到什么：** 子问题反复出现，当前答案依赖更小状态；最关键的是定义状态，而不是直接写转移式。

- 依次回答：`dp` 表示什么？最后一步有哪些选择？边界值是什么？按什么顺序计算？答案在最后一格还是所有状态的最大值？
- **以当前位置结尾：** 适合“连续”或必须使用当前项的状态，见 [53 最大子数组和](11-dynamic-programming.md#q-53)。**两个前缀：** 分析两串之间的关系，见 [1143 最长公共子序列](11-dynamic-programming.md#q-1143)。与要求连续的 [718 最长重复子数组](11-dynamic-programming.md#q-718)对照，不匹配时转移不同。
- **选择与计数：** [416 分割等和子集](11-dynamic-programming.md#q-416)判断能否凑出目标，[518 零钱兑换 II](11-dynamic-programming.md#q-518)统计组合数；状态类型和循环方向都取决于“每个元素能用几次、是否区分顺序”。

## 12 字符串与规则模拟

**看到什么：** 解析格式、逐字符处理、进位或输出格式规则。先写出状态和阶段，再开始编码。

- **扫描器：** 当前读到哪一类字符、何时停止、溢出时怎样处理。见 [8 字符串转换整数](12-string-simulation.md#q-8)。
- **分段规则：** 边界、前导零、合法字符和值域分别检查。见 [165 比较版本号](12-string-simulation.md#q-165)、[468 验证 IP 地址](12-string-simulation.md#q-468)。
- 用普通输入和边界输入分别手推；不要凭一个示例把题目规定以外的规则加进去。

## 13 位运算与概率

**看到什么：** 固定出现次数、统计二进制位、从已有随机源构造均匀随机结果。先证明性质与输入前提。

- **消对与逐位：** 恰有一个元素出现一次、其余都出现两次时可用异或，见 [136 只出现一次的数字](13-probability-bit.md#q-136)；求二进制 `1` 的数量可利用 `x & (x-1)`，见 [338 比特位计数](13-probability-bit.md#q-338)。
- **均匀映射：** 把等概率的基础结果组合成等概率空间，舍弃多余区域后重新采样，见 [470 用 Rand7() 实现 Rand10()](13-probability-bit.md#q-470)。要解释每个最终值获得多少个等概率来源。

## 容易选错方法的分叉

| 先检查的条件 | 典型分叉 |
| --- | --- |
| 连续区间是否有单调性？ | [209 正数最短达标区间](02-sliding-window-prefix.md#q-209)用窗口；[560 可含负数的和为 K 计数](02-sliding-window-prefix.md#q-560)用前缀频次。 |
| 要一个结果还是全部方案？ | [55 能否跳到终点](10-greedy-interval.md#q-55)维护可达范围；[46 全排列](09-backtracking.md#q-46)必须枚举路径。 |
| 子序列能否跳过元素？ | [1143 最长公共子序列](11-dynamic-programming.md#q-1143)允许跳过；[718 最长重复子数组](11-dynamic-programming.md#q-718)要求连续。 |
| 图的访问标记是否需要撤销？ | [200 岛屿数量](08-graph-search.md#q-200)永久标记；[79 单词搜索](09-backtracking.md#q-79)只在当前路径上禁止重复。 |
| 返回给父节点的值是否等于最终答案？ | [124 二叉树中的最大路径和](07-tree.md#q-124)向上传单支，答案可在当前节点连左右两支。 |

复习时先遮住上表的右栏，自己说出**前提、状态和排除理由**；卡住了再进入链接题解。能迁移到同类新题，比记住某题使用了哪个模板更接近面试所需的能力。
