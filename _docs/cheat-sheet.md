这页用于 **面试前快速唤醒**，不是替代完整推导。看到题目先找结构和约束，再选模式；如果只记得“这题用滑窗 / DP”，但讲不出为什么，就回到[题型识别与解题套路](pattern-guide.md)。

## 60 秒决策顺序

拿到题先问：

1. **求什么**：存在、最值、计数、还是全部方案？
2. **范围是什么**：连续区间、任意子序列、子树、路径、整个图？
3. **有什么性质**：有序、单调、全正、无权、BST、固定值域？
4. **需要记住什么状态**：已处理区域、历史前缀、候选集合、递归返回值、DP 状态？
5. **为什么能排除其他选择**：指针移动、二分丢半、单调结构弹出、贪心决定是否有证明？

## 五类高频分叉

### 1. 滑动窗口 vs 前缀和

- **正数 + 达到阈值 + 求最短 / 最长**：常可利用窗口单调移动，例如 209；
- **可含负数 + 精确等于 k + 求计数**：优先考虑前缀和频次，例如 560。

核心不是“连续就滑窗”，而是窗口变化是否具有可利用的单调性。

### 2. DFS / BFS vs 回溯

- **连通性 / 遍历所有可达节点**：访问后通常永久标记；
- **当前路径不能重复，但其他路径还能使用**：退出递归时要撤销。

对照 200 与 79。

### 3. Tree DFS 返回值 vs 全局答案

先完成一句话：

> `dfs(node)` 返回 ______ 给父节点。

例如 124 向上传的是“单支最大贡献”，但全局答案可以在当前节点把左右两支连起来。

### 4. 0/1 背包 vs 完全背包

- 每件物品最多一次：一维压缩时金额通常倒序；
- 当前物品可以重复：金额可以正序。

循环方向来自“本轮能不能读到刚更新的当前物品状态”，不是死口诀。

### 5. 子序列 vs 连续子数组

- LCS / LIS 可以跳过元素；
- 最长重复子数组要求连续，不匹配时当前结尾状态归零。

先定义状态是否“必须以当前位置结尾”。

## 面试口述模板

编码前尽量用 30～60 秒完成：

1. **澄清条件**：有序吗？有重复吗？有负数吗？能改输入吗？
2. **直接方案**：最朴素的方法是什么，瓶颈在哪里？
3. **利用性质**：单调性、重复子问题、前缀差、树递归结构、局部支配？
4. **定义状态 / 不变量**：left/right、栈里元素、dfs 返回值、dp 含义分别是什么？
5. **说明排除理由**：为什么移动指针、弹栈、丢半边或做贪心不会漏答案？
6. **编码后手推**：普通例 + 边界例；
7. **复杂度**：时间、辅助空间，递归栈单独算。

## 高频实现检查

写完代码后快速扫一遍：

- 空输入 / 单元素；
- 重复值；
- 负数是否改变算法前提；
- 下标是否越界，`left <= right` 还是 `left < right`；
- 是否意外修改输入；
- 整数相加、比较器、编号是否可能溢出；
- BFS 是否在入队时标记；
- 回溯是否复制结果、撤销共享状态；
- Tree DFS 是否混淆“向上传值”和“全局答案”；
- DP 压缩后更新顺序是否改变依赖；
- 输出空间和辅助空间是否混写。

## 卡住时不要继续背代码

如果 1 分钟内不知道怎么开始，按这个顺序回退：

> 题目目标 → 输入性质 → 状态定义 → 可排除的选择 → 对应章节

只有在能解释这五步后，再去记实现细节。
